## Тестирование SPaySdk

Для проверки работоспособности **SPaySdk** с учетными данными, полученными от Банка, выполните
следующие шаги:

* **Maven** — добавьте в файл `local.properties` параметры доступа к Maven-репозиторию:

    * `name`
    * `url`
    * `username`
    * `password`

* **AAR** — поместите полученные `.aar`-библиотеки в директорию `../libs` корня проекта и проверьте, что имена
  файлов соответствуют зависимостям, указанным в `build.gradle`.

Перед запуском тестового сценария укажите:

* `api_key`
* `merchantLogin`
* `bankInvoiceId`
* остальные обязательные параметры, необходимые для выбранного сценария.

После заполнения параметров запустите необходимый сценарий с помощью соответствующей кнопки в
тестовом приложении.

Актуальные версии библиотек и документация по интеграции доступны на портале:

https://sdkpay.github.io/SberPaySdkAndroidDoc/
